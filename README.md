# YYCount – Калькулятор условных установок

**YYCount** – это простое десктопное приложение на WPF для расчёта условных установок (у.е.) на основе оборудования. Приложение позволяет вести справочник оборудования, создавать расчёты с историей и редактировать данные прямо в таблице.

## Особенности

- Справочник оборудования (название, количество условных установок за единицу).
- Создание расчётов с выбором оборудования и указанием количества.
- Автоматический расчёт итогов по каждой позиции и общая сумма.
- Редактирование позиций прямо в таблице (количество, название, усл. за ед.).
- История всех расчётов с возможностью открытия, удаления и поиска.
- Хранение данных локально в JSON-файлах (`%AppData%\YYCount`).
- Горячие клавиши: `Ctrl+S` для сохранения расчёта.
- Политика конфиденциальности: все данные сохраняются только на вашем устройстве, никакая информация не передаётся третьим лицам.

## Технологии

- .NET 6 / .NET Core
- WPF (Windows Presentation Foundation)
- MVVM паттерн
- JSON для хранения данных
